# 四人纪念 · In Memoriam Quattuor

> 一座给四个人的小教堂：**共同时间轴 · 相册墙 · 私人唱片 · 留言与献花**。
> 纯静态、零依赖、可离线运行；照片、视频、音乐全部只存在访客自己的浏览器里，不上传任何服务器。

哥特维多利亚风格：尖拱窗、花饰分隔线、哥特体标题、烛光与浮尘、黄铜与红酒色。
整站由两个样式文件与三个脚本构成，没有构建步骤、没有框架、没有 npm 依赖 —— 双击 `index.html` 即可运行。

> **示例内容为虚构演示。** 阿尘、阿屿、小满、鹿野四人与整条时间轴都是为展示版式而写的虚构故事，
> 不对应任何真实人物。请把它们换成你自己的名字与记忆后再公开发布（见「换成你们自己的」）。

## 一分钟上手

1. 打开 `index.html`（Chrome / Edge / Firefox 均可，支持 `file://` 直接双击）。
2. 点右下角 **🔓 锁形按钮** 进入编辑模式。
3. 直接点页面上任何文字修改它 —— 名字、生卒年月、评语、序言、页脚；改完点空白处自动保存。
4. 编辑模式下点相册墙里的 **「＋ 上传照片 / 视频」**（可多选）；点拱廊卡片右上角的按钮可单独换肖像。
5. 进入任意一人页面，在 **唱片与声音** 一节点 **「上传你们的音乐」**。
6. 改完点 **「导出备份」** 存一份 JSON。换电脑、清缓存前请务必导出。

## 页面上有什么

| 位置 | 内容 |
| --- | --- |
| `index.html` 首屏 | 站名、献词、年份区间、影像与花朵计数；背景是缓慢旋转的玫瑰窗 |
| 序 | 一段可自由改写的说明（`site.story`） |
| 四人拱廊 | 四扇尖拱窗，各带铭牌（姓名 / 生卒 / 一句评语），点进个人页 |
| 共同时间轴 | 滚动时金色进度线跟着走；条目可增删改 |
| 相册墙 | 瀑布式影像墙：上传、改标题说明、指定归属、点击放大（灯箱支持 ← → 翻页） |
| 留言与献花 | 留言纸条 + 献花按钮（点击落英缤纷），可写给所有人或某一个具体的人 |
| `person.html?id=pX` | 单人页：肖像、身份字段、专属时间轴、私人影音、唱片机、专属留言、其余三人条与前后翻阅 |

顶部右侧三个按钮：**🕯 管风琴氛围音**（纯 WebAudio 合成的持续低音与钟声，不需要任何音频文件）、
**☀/☾ 明暗主题**（夜晚的石与烛火 ↔ 白昼的羊皮纸与墨）、**🔓 编辑模式**。

│  ├─ js/media.js             IndexedDB 媒体库 + 唱片机 + 氛围音合成

## 换成你们自己的

- **改配色 / 字体 / 圆角**：只动 `assets/css/theme.css` 顶部的 `:root` 令牌，全站跟着变。
- **改默认文案**：`assets/js/store.js` 的 `defaults()`。
- **加一篇时间轴**：页面上「添加时刻」，按 `年份 | 年龄 | 标题 | 一句话` 填写。
- **加第五个人**：目前是四人固定结构（`p1`–`p4`）。复制一张拱廊卡片、在 `defaults().people` 里加 `p5`，
  并把 `assets/js/app.js` 里的 `PEOPLE_ORDER` 补上 —— 其余逻辑会自动适配。

### 数据存在哪里

| 内容 | 位置 | 容量 |
| --- | --- | --- |
| 文字（姓名、时间轴、留言、音轨标题…） | `localStorage` 键 `vic-memorial:v1` | 约 5 MB |
| 小图 / 小音频（≤ 12 MB） | 内联在 localStorage 数据里 | 受上行额度所限 |
| 大图 / 视频 / 大音频 | `IndexedDB` 库 `memorial-media` | 通常数百 MB |
| 肖像 | `localStorage` 键 `vic-memorial:portrait:pX` | — |

换浏览器、换电脑、清空浏览数据都会丢失，因此项目内置了「导出备份」。
备份的 JSON 只含文字与媒体索引，二进制文件仍在浏览器库中 —— 换机时请把原始照片一起带走。

## 自检

```bash
node tools/smoke.mjs --page=home
node tools/smoke.mjs --page=person --id=p3
node tools/capture.mjs                 # 生成 preview/ 下的截图，需本机 Chromium 内核浏览器
```

冒烟测试在极简 DOM 桩中**真实执行**三个脚本，核对：绑定路径有效、时间轴/留言/相册墙渲染、
`data-text` 容器不吃掉子元素、人物页身份按 `?id=` 正确替换、编辑模式可进出、献花与留言可读写。

### URL 调试参数

- `?preview=1` 或 `?smooth=0`：关闭平滑滚动，便于截图与锚点直达。
